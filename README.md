# 📊 Production Dashboard — Excel Data Analysis

## 📌 Project Overview

This project is an interactive **Production Dashboard created using Microsoft Excel** to analyze production performance, costs, units produced, product categories, managers, regions, and workforce-related information.

The dashboard was built using a production dataset and Excel analytical features such as **Pivot Tables, Pivot Charts, formulas, and dashboard visualizations**.

## 🛠️ Tools & Skills Used

* Microsoft Excel
* Data Cleaning
* Data Analysis
* Pivot Tables
* Pivot Charts
* Excel Formulas
* Data Aggregation
* Dashboard Design
* KPI Analysis
* Data Visualization

## 📂 Dataset

The dataset contains production-related information including:

* Production ID
* Production Date
* Region
* Manager
* Product Type
* Units Produced
* Total Cost
* Gender
* Age
* Age Group

The dataset contains approximately **120 production records**.

## 📊 Dashboard Analysis

The dashboard provides insights into:

* Production performance
* Total units produced
* Production costs
* Product-type performance
* Manager-wise task/production information
* Production trends
* Product cost analysis
* Regional and workforce-related data

## 📈 Excel Analysis

I created multiple Pivot Tables to summarize the dataset, including:

### Pivot 1 — Total Cost by Product Type

Analyzes the total production cost associated with different product categories.

### Pivot 2 — Tasks by Manager

Provides a manager-wise view of tasks/production records.

### Pivot 3 — Units Produced

Analyzes production volume over time.

### Pivot 4 — Product Cost Analysis

Compares product-level cost metrics.
